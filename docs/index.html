Artale裝備效益計算機

本計算機以表攻計算讓玩家快速知道攻屬比效益以及換裝表攻提升。
DPS、攻速、命中效益、技能內建效果牽涉範圍複雜不在計算範圍內。
實戰影響輸出因素眾多，表攻僅供參考，請勿完全盲信。
